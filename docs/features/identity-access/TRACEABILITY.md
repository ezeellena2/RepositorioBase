## How to read the Evidence column

The column used to say `Pending` for everything no task had explicitly written a line about, which read as "not
implemented" and was wrong for most of those rows. It now says what was actually looked for and what was found:

- **Covered** — every part of the planned evidence is named here, and the named tests exist and run in
  `dotnet test CleanArchitecture.slnx`.
- **Partial** — some of it is named here and the rest is stated as a gap, in the same cell.
- **Not covered** — nothing in the suite demonstrates it.

`Covered` is a statement about evidence, not an approval: it says the behaviour is demonstrated by tests that run,
not that IA-014 or anyone else has signed the requirement off. Rows still keep the normative owner they had, and
IA-009 supplies end-to-end acceptance evidence without ever being a normative owner.
